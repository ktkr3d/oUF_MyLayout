# [oUF_MyLayout](https://github.com/ktkr3d/oUF_MyLayout)

## Introduction

oUF_MyLayout is a unit frame addon.

## Install

Install oUF_MyLayout using the [WowUp](https://wowup.io/guide/get-addons/overview) app.

`Get Addons` > `Install from URL`

```text
https://github.com/ktkr3d/oUF_MyLayout
```

## Configuration

```text
/mylayout config
```
